# Recomendador de Filmes (PT-BR)
O projeto consiste em uma aplicação web desenvolvida em Python utilizando o framework Flask, que recomenda filmes a partir de um título informado pelo usuário. A aplicação se integra à API pública do The Movie Database (TMDb) para buscar o filme digitado e, a partir do seu ID, obter uma lista de filmes recomendados relacionados. O usuário acessa uma página web com interface simples em vermelho e preto, digita o nome de um filme em um campo de busca (com sugestões automáticas enquanto digita) e, ao enviar o formulário, recebe na mesma página uma listagem de até 20 filmes recomendados, exibidos com pôster e título em formato de cards. Toda a lógica de busca e recomendação é feita no back-end com Flask, utilizando requisições HTTP à API da TMDb, e o front-end é renderizado com templates HTML.

# Movie Recommendation System (ENG)

This project is a web application built with Python and the Flask framework that recommends movies based on a title entered by the user. The application integrates with the public The Movie Database (TMDb) API to search for the selected movie and retrieve a list of related movie recommendations using its unique ID. Users interact with a clean red-and-black themed interface where they can type a movie title into a search bar with real-time autocomplete suggestions. After submitting the form, the application displays up to 20 recommended movies on the same page, presented as card components containing each movie’s poster and title. All search and recommendation logic is handled on the back end using Flask and HTTP requests to the TMDb API, while the front end is rendered with HTML templates.
